# 📚 Documentação do Projeto GreenER

Bem-vindo à central de documentação técnica e de processos do **GreenER**, desenvolvido pela equipe **Undefined** no 3º semestre do curso de Desenvolvimento de Software Multiplataforma (FATEC Jacareí).

Este diretório contém todos os artefatos de engenharia de software, modelagem, cálculo e processos ágeis exigidos pela rubrica de avaliação interdisciplinar.
